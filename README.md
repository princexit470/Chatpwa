# XIT Messenger

Secure messaging with voice & video calls.

## Features
- Real-time chat
- Voice & video calls (WebRTC)
- Status updates
- Private rooms
- Stealth mode
- Call history
- PWA installable

## Live
Deployed on Render: https://xit-app.onrender.com

## Tech
- HTML/CSS/JS
- Firebase Realtime Database
- WebRTC
- PWA
